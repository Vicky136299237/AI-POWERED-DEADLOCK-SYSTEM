This project is an AI-powered system designed to:

🔍 Detect deadlocks in real-time by monitoring processes and resources.

🧠 Analyze the 4 Coffman conditions (Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait).

⚡ Automatically resolve or suggest resolutions using intelligent heuristics.

📊 Provide a visual dashboard to track deadlock states, system health, and process/resource statuses.

✨ Key Features
✅ Real-Time Monitoring: Constantly checks active processes & resource allocations.

🤖 AI-Based Decision Making: Smart algorithms predict and prevent potential deadlocks.

📈 Intuitive Dashboard: Clean UI with charts, tables, and alerts for quick status checks.

🛠️ Deadlock Resolution: Automatically releases resources or restarts processes as per predefined policies.

🔄 Live Simulation: Test with simulated process-resource data to understand behavior.
